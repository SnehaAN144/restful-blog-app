# RESTful Blogging Platform

A full-stack RESTful blogging application built using Node.js, Express.js, MySQL, EJS, JWT Authentication, and Bootstrap.

## Features

- User Authentication
- JWT Authorization
- Blog CRUD Operations
- Protected Routes
- MySQL Database
- Responsive UI

## Technologies Used

- Node.js
- Express.js
- MySQL
- EJS
- Bootstrap
- JWT
- bcrypt
